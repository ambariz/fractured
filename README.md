# FRACTURED (World 1)

A 2D platformer where players journey through a fractured world by five elemental forces: **Earth, Water, Fire, Wind/Air, and Void**.


Explore the level, collect keys, gather money to open gates, overcome obstacles, and find the main exit to complete the level.

**LINK :** https://ambariz.itch.io/fractured1

---

## Gameplay (See the Screenshots below)

- Move and jump through dangerous platforming sections
- Collect **keys** throughout the level
- Collect **money bags** to open gates
- Discover hidden paths and navigate obstacles
- Find and pass through the **main exit gate**

---

## Controls

- **A / D or Arrow Keys** → Move left/right
- **Space** → Jump
- **X** → Restart after completing a level
- **R** → Restart after completing a level

---

## Features

- Key collection system
- Money collection and progressive gate system
- Main exit system requiring collected keys
- Moving platforms
- Teleporters
- Hidden areas
- Level completion system with UI overlay
- Restart mechanic
- Custom 2D sprites and environments
